# 井然 - 我的桌面管家

欢迎使用“井然”桌面管理软件！本项目目前提供了一个现代化的暗黑风格用户界面（UI）框架。**请注意，目前这只是一个纯UI界面的框架演示，具体的各项功能（如待办事项、密码管理、桌面整理等）都还在开发中，尚未实现具体逻辑。**

下面是为零基础用户准备的安装和运行指南：

## 第一步：安装 Python

本软件需要 Python 3.10 或更高版本来运行。

1. 打开浏览器，访问 Python 官方下载页面：[https://www.python.org/downloads/](https://www.python.org/downloads/)
2. 点击下载最新版本的 Python 安装程序（通常是一个黄色的“Download Python 3.x.x”大按钮）。
3. 下载完成后，双击运行安装程序。
4. **重要提示：** 在安装向导的第一个界面，**一定要勾选**底部的 `Add python.exe to PATH`（将 Python 添加到系统环境变量），然后再点击 `Install Now` 进行安装。
5. 等待安装完成。

## 第二步：安装所需依赖

本软件使用了一些第三方的代码库（如 customtkinter 和 pillow），我们需要先把它们下载安装好。

1. 在你的电脑上打开“命令提示符”或“终端”：
   - Windows 用户：按下键盘上的 `Win` 键，输入 `cmd`，然后按回车键打开。
   - Mac 用户：按下键盘上的 `Command + 空格` 键，输入 `Terminal` 或 `终端`，然后按回车键打开。
2. 使用命令行进入到本项目的 `jingran` 文件夹目录。如果你不知道怎么进入，也可以在文件资源管理器中打开 `jingran` 文件夹，然后在地址栏中输入 `cmd` 并按回车键。
3. 在命令行窗口中，输入以下命令并按回车键：
   ```bash
   pip install -r requirements.txt
   ```
4. 耐心等待系统自动下载并安装所需的文件，直到看到类似“Successfully installed...”的成功提示。

## 第三步：运行软件

现在一切准备就绪，可以运行软件了！

1. 保持在刚才打开的命令行窗口（确保当前目录仍在 `jingran` 文件夹下）。
2. 输入以下命令并按回车键：
   ```bash
   python main.py
   ```
   *注意：如果在 Mac 上，可能需要输入 `python3 main.py`*
3. 稍等片刻，你应该就能看到“井然 - 我的桌面管家”的精美界面了！
