# PDF文献重命名工具

这是一个用于批量识别并重命名本地 PDF 文献的工具。它可以自动提取论文标题，并将 PDF 重命名为“论文标题.pdf”。

## 声明
- **本工具完全在本地运行，PDF 文件不会上传到任何服务器。**
- 如果勾选“使用 DOI/Crossref 联网识别标题”，只会发送提取到的 DOI 字符串，不发送 PDF 内容。

## 使用说明 (针对零基础用户)

### 1. 如何安装 Python
1. 打开浏览器，访问 Python 官网: https://www.python.org/downloads/
2. 下载适用于 Windows 的最新版本 Python 3 (建议 3.10 或更高版本)。
3. 双击下载的安装包。
4. **【非常重要】** 在安装界面的底部，**必须勾选 "Add python.exe to PATH"** (将 Python 添加到环境变量)。
5. 点击 "Install Now" 进行安装，等待完成。

### 2. 如何解压项目
1. 将下载的工具压缩包文件 (`.zip`) 保存到您的电脑上 (建议不要放在有中文名字或特殊符号的文件夹里)。
2. 右键点击压缩包，选择 "解压到当前文件夹" 或 "全部提取..."。
3. 打开解压出来的文件夹，您应该能看到 `app.py`，`requirements.txt`，`README.md`，`build_exe.bat` 等文件。

### 3. 如何安装依赖
1. 在解压后的文件夹内，按住键盘上的 `Shift` 键，然后在文件夹空白处点击鼠标右键。
2. 选择 "在此处打开 PowerShell 窗口" 或 "在此处打开命令行窗口"。
3. 在弹出的黑色窗口中，输入以下命令并按回车键 (`Enter`)：
   ```
   pip install -r requirements.txt
   ```
4. 等待安装完成 (屏幕上会显示很多下载和安装信息，如果没有出现红色错误信息，就说明安装成功)。

### 4. 如何运行 app.py
在刚才的黑色命令行窗口中，继续输入以下命令并按回车键：
```
python app.py
```
这会打开“PDF文献重命名工具”的图形界面。

### 5. 如何打包成独立的可执行文件 (exe)
如果您希望以后双击一个图标就能直接运行，而不需要每次都打开命令行，可以将其打包成 `.exe` 文件。
1. 在项目文件夹中，双击运行 `build_exe.bat` 文件。
2. 此时会弹出一个黑色窗口自动执行安装和打包过程，这可能需要几分钟的时间，请耐心等待。
3. 看到提示“请按任意键继续...”时，说明打包完成，您可以按任意键关闭窗口。
4. 打包完成后，**exe 文件会生成在 `dist` 文件夹中**，文件名为 `PDF文献重命名工具.exe`。您可以将其复制到桌面上方便使用。

## 注意事项

- **使用前先备份 PDF**：虽然工具提供了撤销功能，但在进行批量重命名之前，为了以防万一，强烈建议您先备份原始的 PDF 文件夹。
- **先预览再执行**：建议先点击“扫描预览”按钮，在表格中确认识别的标题和新文件名是否正确。如果需要，您可以双击表格中的新文件名手动修改。确认无误后，再点击“执行重命名”。

## 常见错误与排查方案

1. **文件被占用**：如果 PDF 文件正在被其他程序 (例如 Adobe Reader、浏览器或 WPS) 打开，程序将无法对其进行重命名。请关闭正在阅读该文件的所有程序后再试。
2. **权限不足**：如果您没有修改该文件夹或文件的权限，或者文件被设置为“只读”(程序会尝试自动取消只读，但可能因系统权限而失败)，重命名将会失败。请确保您对文件夹拥有完全控制权限。
3. **路径太长**：Windows 系统对文件路径长度有 260 个字符的限制。如果文件夹路径过长，加上文件名后超出了限制，会导致操作失败。建议将 PDF 文件夹移动到较浅的目录 (例如 `D:\PDFs`) 下再操作。
4. **杀毒软件误报**：打包后的 `.exe` 文件有时可能会被 360 等杀毒软件误报为病毒并拦截。这是因为打包工具 PyInstaller 的特征导致的。您可以将其加入杀毒软件的信任列表或白名单。
